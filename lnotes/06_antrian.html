Simulasi Model Antrian

Simulasi Poisson process sebenarnya sangat sederhana dan sangat bagus untuk membantu mahasiswa memahami konsep arrival acak dalam sistem.

Kita akan mensimulasikan dua hal:

  1. jumlah kejadian dalam waktu tertentu (Poisson)
  2. waktu antar kejadian (Exponential)

Ini langsung menunjukkan hubungan teori yang kita bahas sebelumnya.

1. Simulasi Poisson Process dengan Python

Ide dasar:

  • waktu antar kedatangan mengikuti Exponential
  • kita terus menambahkan waktu sampai melewati batas waktu total

Contoh: simulasi request server selama 10 detik.

import numpy as np
import matplotlib.pyplot as plt

## parameter
lambda_rate = 2   ## rata-rata 2 request per detik
T = 10            ## total waktu simulasi (detik)

arrival_times = []
t = 0

while t < T:
    ## generate waktu antar kedatangan
    interarrival = np.random.exponential(1/lambda_rate)
    t += interarrival
    
    if t < T:
        arrival_times.append(t)

print("Arrival times:", arrival_times)
print("Total arrivals:", len(arrival_times))

3. Simulasi Distribusi Poisson

Sekarang kita simulasi jumlah kejadian dalam interval waktu tetap.

lambda_rate = 4   ## rata-rata 4 kejadian
samples = np.random.poisson(lambda_rate, 10000)

plt.hist(samples, bins=15, density=True)
plt.xlabel("Number of events")
plt.title("Poisson Distribution Simulation")
plt.show()

Ini akan menghasilkan histogram yang mengikuti distribusi Poisson.

4. Simulasi Waiting Time (Exponential)

Kita lihat distribusi waktu antar kedatangan.

interarrival = np.random.exponential(1/lambda_rate, 10000)

plt.hist(interarrival, bins=50, density=True)
plt.xlabel("Waiting time")
plt.title("Exponential Distribution")
plt.show()

Mahasiswa akan melihat bahwa:

  • banyak waktu tunggu pendek
  • beberapa panjang

Ini ciri khas exponential distribution.

6. Simulasi M/M/1 Queue (bonus kecil)

Contoh sangat sederhana:

arrival_rate = 2
service_rate = 3

n = 1000

interarrival = np.random.exponential(1/arrival_rate, n)
service_time = np.random.exponential(1/service_rate, n)

arrival_time = np.cumsum(interarrival)

start_service = np.zeros(n)
finish_service = np.zeros(n)

for i in range(n):
    if i == 0:
        start_service[i] = arrival_time[i]
    else:
        start_service[i] = max(arrival_time[i], finish_service[i-1])
    
    finish_service[i] = start_service[i] + service_time[i]

waiting_time = start_service - arrival_time

print("Average waiting time:", np.mean(waiting_time))

Ini sudah menjadi simulasi dasar sistem antrian.

7. Insight penting untuk mahasiswa

Dengan simulasi ini mahasiswa melihat bahwa:

random events
→ Poisson arrival
→ Exponential waiting time
→ queueing systems

Ini membuat probabilitas terasa hidup, bukan sekadar rumus.

Rantai Distribusi Probabilitas dalam Engineering

Bernoulli → Binomial → Poisson → Exponential → Queueing Theory

Kita bahas satu per satu secara intuitif.

1. Bernoulli — kejadian dasar (sukses / gagal)

P(X=1)=p,; P(X=0)=1-p

Bernoulli adalah atom dari probabilitas diskrit.

Contoh:

  • bit diterima benar / salah

  • packet berhasil / hilang

  • komponen hidup / gagal

Ini adalah model kejadian tunggal.

Dalam engineering digital:

error bit = Bernoulli trial

2. Binomial — jumlah sukses dalam n percobaan

\[ P(X=k)=\binom{n}{k}p^k (1-p)^{n-k} \]

Jika kita melakukan banyak Bernoulli trial, kita mendapat distribusi Binomial.

Contoh engineering:

  • jumlah error dalam 1000 bit

  • jumlah packet loss dalam 100 transmisi

  • jumlah mahasiswa lulus ujian

Binomial menjawab:

berapa banyak kejadian sukses dalam n percobaan

3. Poisson — kejadian langka dalam waktu/ruang

\[ P(X=k)=\frac{\lambda^k e^{-\lambda}}{k!} \]

Jika:

  • percobaan sangat banyak

  • probabilitas sukses sangat kecil

maka Binomial menjadi Poisson.

Parameter:

\[ \lambda = np \]

Contoh nyata engineering:

  • jumlah request web per detik

  • jumlah kendaraan lewat per menit

  • jumlah error per MB data

Poisson menjawab:

berapa kejadian dalam interval waktu

4. Exponential — waktu antar kejadian

Jika kejadian mengikuti Poisson process, maka jarak waktu antar kejadian mengikuti distribusi Exponential.

\[ f(t)=\lambda e^{-\lambda t} \]

Contoh:

  • waktu antar telepon masuk

  • waktu antar packet arrival

  • waktu antar kegagalan komponen

Ini sangat penting karena memiliki sifat:

memoryless

Artinya:

masa depan tidak bergantung masa lalu.

5. Queueing Theory — sistem pelayanan

Jika:

  • arrival mengikuti Poisson

  • service time mengikuti Exponential

maka kita mendapatkan model antrian klasik:

M/M/1 queue

dimana

simbol arti
M Markov (Poisson arrival)
M exponential service
1 satu server

Model ini dipakai untuk:

  • server komputer

  • call center

  • jaringan internet

  • sistem produksi

6. Diagram besar probabilitas sistem teknik

Struktur besar:

kejadian dasar      ↓ Bernoulli trial      ↓ Binomial (jumlah sukses)      ↓ Poisson (kejadian per waktu)      ↓ Exponential (waktu antar kejadian)      ↓ Queueing systems

Ini adalah salah satu rantai konsep paling penting dalam engineering systems.
